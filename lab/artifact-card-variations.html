Artifact card: four variations

Four ways to show a file the agent made, all with the same report: Pricing page review, in three versions. Each one plays its writing state first. Open it, switch versions, copy or download it, or press Replay.

1Compact file card

The pattern people already know: an icon, the name, one line of meta and Open. Dense enough to stack several in a thread.

2Card with a preview

The same card with the first page showing, so drafts are easy to tell apart. The page grows into the reader when you open it.

3Inline attachment

One line inside the message, like a file you attached. Versions and actions fold out on hover or focus, so the reply stays prose.

4Version stack

The report as a stack of paper. You watch the new page being written onto it, and fan the sheets out to pick a version.
