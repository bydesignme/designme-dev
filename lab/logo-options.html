Notes

  • Every path is drawn here from lines, arcs and squares; no font is used, so the files are pure vectors.
  • On the page the logos take the site's colour roles: --accent-fg for accent letters, --accent-mark for marks, --accent for fills with --on-accent on top. On Blueprint light that makes accent letters ink, as the site does for all accent text.
  • The downloadable files are fixed colours for a light background: ink #121212 and Soft blue #116ff8. Option 3's mark file shows the switch turned on.
  • With reduced motion nothing moves. Option 3's switch fades to the accent instead of sliding.
