Clean review, Phase I

Everything this review changes, compared with what is on staging now, grouped by component in the order of the review batches. Each name opens that component's page in Clean (?style=clean): change it to ?style=soft or ?style=bp for another style, and add &theme=light or &theme=dark for a mode. "Every style" means Soft, Blueprint and Clean; where a line names one style, only that style changed. This is a preview only: staging and the live site don't have these changes yet.

Across the library

  • One hover and one selected state in Clean. Every row, option, segment, tab and ghost or icon button uses the same quiet see-through grey on hover, and the same shape a step stronger when it is selected, on or open. It shows clearly in light and dark, eases in and out over 220ms, and never uses a border or a colour.
  • Ghost and icon buttons share one hover in Clean: the quiet grey in the button's own shape, with no edge, shadow or size change. A button that is on, pressed or holding its menu open keeps the stronger fill, even under the pointer. The one-off hovers some components had (darker greys, rings, their own tints) now use it.
  • A gliding highlight in Clean menus and lists. One highlight slides from row to row as the pointer or the arrow keys move, and fades in and out as the pointer enters and leaves. Every component's menus have it, and so do the lists in Agent inbox, Workspace rail, Command palette, File explorer, Knowledge sources, Health score, Score breakdown, Date picker, Segmented control, Agenda, Tooltip, Search input, Notifications, Context switcher, Ticket list and Donut chart's legend. With reduced motion it only fades.
  • Clean's accent is white in dark mode and stays blue in light mode. Everything drawn in the accent turns white in Clean dark, with dark words on white fills: loaders, spinners, animated dots, progress and step bars, playheads, selected marks, toggles, count badges, links (which keep their underline) and accent text. Status colours, agents' own colours, avatars and the chart palette's other colours keep their hues.
  • Clean's head and foot strips: the controls in them now sit on the content's 16px column at the sides, 8px from the strip's top and bottom. Before, they sat 8px from the card's edge.
  • Footers are set apart. In Soft and Blueprint, a card's footer (its buttons, or a status line) sits under a hairline divider. In Clean it is an off-white foot strip.
  • A field's own Send button in Clean (Comments, Composer, Attachment tray, Agent lanes): a quiet glyph while the field is empty, then the black button fades in once there is something to send. It sits in the field's corner with even room round it.
  • Nothing shrinks or grows on a click, in every style. Only Clean's black primary button presses in.
  • Switchers in Clean: a segment that isn't picked shows the one hover under the pointer. Segmented control now uses Clean's own switcher, a white knob on a grey track.
  • Data tables work like a spreadsheet (Task table, Account table): a line between every two columns in every style, columns you can resize by dragging a header's edge (or with the arrow keys), and columns you can move by dragging a header (or with Alt and an arrow key). A double-click on an edge resets the widths.
  • More demos keep playing while the pointer rests on them, as an agent at work does: Response versions, Memory panel, Tools and connections, Knowledge sources, Scheduled runs, Event calendar, Form and Comments. The person's own steps in these demos still wait for the pointer to leave.
  • Small fixes everywhere: a keyboard shortcut chip inside a tooltip now reads on Clean's white tooltip. Key presses played by another card's demo no longer bring back a focus ring after a click.
  • React installs carry all of the above, including the gliding hover and the resizable, movable table columns. Card heights were measured again for the changed components.
