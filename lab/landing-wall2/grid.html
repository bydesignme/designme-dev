Three styles, light and dark

One set of components, drawn three ways. Drag the handles to compare the same Decision prompt in each. It’s live, and all three answer together.

BlueprintSoftClean

Blueprint needs no attribute. Soft and Clean are data-style on <html>, and dark mode is data-theme="dark".

Square corners, hairline edges and a lime accent, like a technical sheet. <html>

Rounded, plush surfaces with a blue accent. <html data-style="soft">

Black, white and grey, with fully round controls. Data keeps its colours. <html data-style="clean">

One command, and the code is yours

The CLI copies a component into your project, one file for each part, so the code is yours.

Installation
$npx designme add permission-gate

Open demo.html to see it working, then copy its markup into your page.

$npx designme add permission-gate --react

A typed component that brings its own CSS, for React 19 and up.

$npx designme add permission-gate --astro

The same markup, CSS and script as the HTML one, as an .astro component.

$npx shadcn@latest add https://designme.dev/r/shadcn/permission-gate.json

Every component is also a shadcn registry item, in React or in Astro.

More in the FAQ
Is it free?

Yes. Every component is free for personal and commercial work under the MIT licence. Fonts, icons, flags and brand marks from other projects keep their own licences, listed in NOTICE.md.

What do I need?

Node 18 or later to run the CLI. The React components need React 19 and work in Next.js, Vite and Astro islands. The HTML version needs only the shared core, which the CLI adds once.

Do I need Tailwind or shadcn/ui?

No. The components bring their own CSS. If your project uses shadcn/ui or Tailwind v4, the theme bridge (--theme-bridge) gives them your theme, and the shadcn CLI can add any of them.

Will their CSS clash with mine?

No. Every CSS variable starts with --dm-, and in React every class and animation name starts with dm- too, so nothing meets your own names.

Are they accessible?

They come with ARIA roles and labels, live regions for what the agent is doing, keyboard support in most components, tap areas on touch screens, and reduced motion.

What are Blueprint, Soft and Clean?

Three styles for the same components: Blueprint is technical and square with a lime accent, Soft is rounded with a blue accent, and Clean is black, white and grey with fully round controls. Each has a light and a dark theme. In your project, data-style on <html> picks one.

Can AI coding tools use it?

Yes. Every component and docs page has a Markdown copy at its address plus .md, and llms.txt lists every component with its install command. The Using with AI page in the docs has prompts to start from.

It is in progress on the roadmap. Leave your email in the library and you will get it when it lands.
