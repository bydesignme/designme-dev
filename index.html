The HTML, CSS and JavaScript for that component. It needs the shared core once, which holds the tokens, icons and small helpers, and you can copy that from the code view, or run npx designme add with the component name and both land in your project.
Yes. Every component comes in HTML, React and Astro: run npx designme add with the component name and --react or --astro, and the component lands in your project with its styles.
