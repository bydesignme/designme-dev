The HTML, CSS and JavaScript for that component. It needs the shared core once, which holds the tokens, icons and small helpers, and you can copy that from the code view, or run npx designme add with the component name and both land in your project.
Yes. Every component comes in HTML, React and Astro: run npx designme add with the component name and --react or --astro, and the component lands in your project with its styles. The React version works in Next.js and React apps, and the shadcn CLI can add either one. To give them your shadcn/ui or Tailwind v4 theme, add the theme bridge with --theme-bridge. A version styled with Tailwind classes is in progress on the roadmap.
It's coming. The Figma library is in progress on the roadmap, with every component in Blueprint, Soft and Clean, light and dark mode and five accent colours, all built on variables so you can restyle it in one place. Sign up and you'll get it as soon as it lands.
Webflow and Framer exports are planned, and you can follow them on the roadmap. Until then the HTML version works in a Webflow embed or a Framer code component.
Three visual styles for the same components. Blueprint is technical and square with a lime accent, Soft is rounded and plush with a blue accent, and Clean is black, white and grey with fully round controls. All three work in light and dark mode. Until you pick one, the site follows your theme: light opens in Soft, dark in Blueprint.
They use proper roles and labels and respect reduced motion, and most work fully with a keyboard. A few, like File explorer, are still getting their keyboard support. Test them in your own product too, since accessibility depends on how they are used.
