Components

80 free components for products built around AI agents, each one as plain HTML, CSS and JavaScript or as a typed React component, in two styles with light and dark mode. Install any of them with npx designme add.

Agent components

Conversation

Everything for asking, answering and replying, by text or by voice.

  • Live answerAnswers that stream in with numbered sources and next steps.
  • ComposerMessage input with context, environment, effort and dictation.
  • Thread panelSwitch between agent threads and reply in place.
  • Artifact cardA file the agent made, with a live preview and versions.
  • Tool callEach tool the agent calls, with its input and output.
  • Voice captureTalk to the agent, then fix what it misheard before sending.
  • Response versionsRegenerate an answer and flip between versions.
  • Prompt startersSuggested tasks that fill the composer in one click.
  • Attachment trayDrop files for the agent and watch each one upload.
  • Feedback sheetRate an answer and tell the agent what missed.

Agent status

Show what the agent is doing, how far along it is, and what it is working with.

  • ThinkingThe live trace, written as the agent works, then folded away.
  • Reasoning trailThe agent's plan, notes, sources and edits, after it thinks.
  • Agent lanesSeveral agents working in parallel, each with its own lane and hand-offs.
  • Run summaryWhat the agent did, what changed and what needs you.
  • Action logEvery read, search, edit and command, logged as it runs.
  • Agent run timelineEvery model and tool step of a run on one time axis.
  • Context meterHow full the context window is, with session and weekly limits, in one small popover.
  • Error and recoveryA failed step with retry, skip or hand over to a person.
  • Run queueGrouped tasks with live progress, retries and a compact view.
  • Run costLive credit and token spend, with a cap that pauses the run.
  • Toast stackAgent notifications that stack and fan out on hover.
  • ToastOne notification that changes shape with its state.
  • Status pillOne live line for what the agent is doing right now.
  • Step loaderNamed steps with a progress track and four loaders.

Review and approve

Moments where a person checks, steers or signs off on the agent's work.

  • Change reviewAccept or reject each change the agent made, file by file.
  • Plan reviewCheck the agent's plan, edit steps, then let it run.
  • Permission gateThe agent asks before it touches something new.
  • Decision promptThe agent asks a few quick questions before it starts.
  • Proposal cardA suggested change with confidence, alternatives and undo.
  • Design tunerTweak a component by hand or let the agent tune it.
  • Rewrite toolbarSelect a sentence and let the agent rewrite it in place.
  • Launch checklistThe agent checks a design before it ships, and fixes what fails.

Sources and output

What the agent read, what it produced and where each answer came from.

  • Code viewerCode the agent wrote, with line notes you can ask about.
  • Citation hover cardHover a citation to see the exact passage it came from.
  • Source stackEverything the agent read, folded into one quiet pill.
  • Field extractionThe agent pulls fields out of a document and shows where each came from.
  • Metric insightA number, its trend, and the agent's read on why it moved.
  • Details panelProperties of a run you can change in place.
  • Task tableAgent tasks in a sortable table with bulk actions.

Workspace

Navigation, search, settings, models and automations around the agent.

  • Automation canvasA trigger, a few agent steps, and a run you can watch flow through.
  • Command paletteJump anywhere or hand a task to the agent from one box.
  • Memory panelWhat the agent remembers about your team, editable and removable.
  • Model compareRun one prompt on three models side by side and keep the best.
  • Agent settingsHow much the agent may do alone, with a save bar for changes.
  • Tools and connectionsThe tools the agent can reach, and how much it may do with each.
  • File explorerProject files, with the ones the agent touched marked.
  • Workspace railA slim app rail that opens into a labelled sidebar.

Harness

  • Agent harnessEvery component working together in one agent app.

App basics

Charts and tables

Lightweight charts and tables for dashboards and reports, drawn in plain SVG and HTML.

  • Line chartTwo series over time with a hover readout and toggles.
  • Bar chartWeekly agent runs, split by outcome, with a range switch.
  • Donut chartWhere the agent's time went, by kind of task.
  • Funnel chartSignup to paid, with the biggest drop called out by the agent.
  • Top pagesMost visited pages with share of traffic and a quick sort.
  • Health scoreA design system score made of a few checks you can open.
  • Activity heatmapWhen the agent and the team were busy, by day and hour.
  • Stat cardsFour headline numbers with sparklines and a period switch.
  • Account tableCustomer accounts with health, plan and an agent note per row.

Dates

Pickers for single dates and date ranges.

  • Date pickerA field that opens a calendar, with quick picks and natural language.
  • Date range pickerPick a start and end across two months, or use a preset.
  • Event calendarA week view where the agent finds a free slot for you.
  • AgendaToday's schedule with a live now line and agent prep notes.

Forms and inputs

Buttons, fields, pickers and sign-in flows for any product.

  • ButtonsEvery button style, with loading, success and hold-to-confirm states.
  • TooltipQuiet labels on hover, with shortcuts and a richer preview card.
  • Search inputSearch with scoped filters, recent queries and an agent answer.
  • Country selectA searchable select with country codes, currency and keyboard support.
  • Social sign-inOne-tap providers that remember the last one you used.
  • Sign inEmail first, then a one-time code that fills itself in.
  • FormA project brief with inline checks and an agent that drafts the rest.
  • Payment formCard details with live formatting, brand detection and a clear total.

Collaboration

Threads, inboxes and boards for teams working alongside an agent.

  • CommentsA design thread where you can @mention the agent and it replies.
  • NotificationsAn inbox where agent updates and mentions arrive live.
  • Invite to collaborateAdd teammates by email as chips, set their role, send.
  • ReactionsQuick reactions on an agent update, with counts that pop.
  • Ticket listSupport tickets the agent has triaged, with suggested replies.
  • Kanban boardA board where you and the agent move cards, with drag and drop.

Product

Pricing, onboarding, setup flows and spending limits for the rest of your product.

  • Pricing cardsThree plans with a billing switch and a seat slider.
  • Onboarding checklistFirst steps with a progress ring, and the agent can do some for you.
  • StepperA multi-step setup with a progress track that fills as you go.
  • Set limitA monthly agent budget with a draggable cap and a forecast.
  • Currency converterShow plan prices in local currency, with a swap and live rate.
