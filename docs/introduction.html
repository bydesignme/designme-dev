Introduction

Designme.dev is a free library of UI components for products built around AI agents.

What it isTwo styles, light and darkWhat is in itHTML, React or AstroFree and MIT licensedNext steps

What it is

125 free components: 75 for the agent itself, like status pills, reasoning trails, tool calls, permission gates, plan reviews and run summaries, and 50 app basics around it.

Every component plays as a demo on the homepage, and has a page of its own with its install command, React props, code and questions.

Two styles, light and dark

  • Soft

    Quiet, rounded surfaces with a blue accent. designme.dev opens in Soft in light mode.

  • Blueprint

    The same components drawn as a technical sheet, with square corners, hairline edges and a lime accent.

Each style has a light and a dark theme. Switch them in the header of any page here. In your own project, two attributes on <html> pick them. See Theming.

There are also 50 app basics, like charts, date pickers and forms, for the product around the agent. They are all in the library.

HTML, React or Astro

Every component comes in three versions. One is HTML, CSS and JavaScript on a small shared core that holds the tokens, icons and helpers. Another is a typed React component for React 19, with no dependencies beyond React, that works in Next.js, Vite and Astro islands. The third is an Astro component with the same markup, CSS and script as the HTML version.

Whichever you pick, the CLI copies the source into your project, so it is yours to change. See Installation and Astro.

Free and MIT licensed

Use the components in personal and commercial work. The code is MIT licensed, and built by DesignMe.

Avatars, icons, flags, brand logos and fonts keep their own licences. They are listed under Credits in the designme package on npm.
