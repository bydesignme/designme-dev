# Introduction

> Designme.dev is a free library of UI components for products built around AI agents.

Designme.dev docs. The same page with navigation: https://designme.dev/docs/introduction

## What it is

102 free components: 65 for the agent itself and 37 app basics around it.

- Agent components: Conversation, Agent status, Review and approve, Sources and output, Workspace and Harness. Status pills, reasoning trails, tool calls, permission gates, plan reviews, run summaries and more.
- App basics: Charts and tables, Dates, Forms and inputs, Collaboration and Product.

Every component plays as a demo on the [homepage](https://designme.dev/), and has a page of its own with its install command, React props, code and questions.

## HTML or React

- HTML, CSS and JavaScript, on a small shared core that holds the tokens, icons and helpers.
- A typed React component for React 19, with no dependencies beyond React. It works in Next.js, Vite and Astro.

Either way, the CLI copies the source into your project, so it is yours to change. See [Installation](https://designme.dev/docs/installation.md).

## Two styles, light and dark

- Soft: quiet, rounded surfaces with a blue accent. designme.dev opens in Soft.
- Blueprint: the same components drawn as a technical sheet, with square corners, hairline edges and a lime accent.

Each style has a light and a dark theme. Switch them in the header of any page here. In your own project, two attributes on `<html>` pick them. See [Theming](https://designme.dev/docs/theming.md).
